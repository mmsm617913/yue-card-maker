# 萬聖節派對 V1

固定配置：`YYH-HALLOWEEN-V1`。九張圖依序為南瓜燈、巫師帽、掃帚、黑貓、蝙蝠、貓頭鷹、小幽靈、糖果、提糖桶。

`catalog-v1.json` 記錄圖像路徑及永久 A/B 面配對。A 面索引 0–8，B 面為下一張、最後一張接回第 1 張。實際 B 面列印仍由既有程式左右鏡像排列，以配合長邊翻紙。

圖像使用已選定的高彩度細節卡通、暖米色背景及淡色萬聖節線稿浮水印。九張獨立素材皆保留完整主體與周圍留白；背景延伸到圖像邊界。

此站點只有 Next.js 靜態匯出。新增配置同步到六個含 `cardCatalog` 的既有 bundle；不得改動既有四個主題的資料與配對。將來取得原始專案時應將此配置移回原始資料模組。新增配對時應另建 V2，不覆寫 V1。

`card-style-v18.css` 只對萬聖節圖片套用滿版與正常遊戲畫面排版。`entry-v18.js` 讓 `?theme=halloween` 直接選取萬聖節主題。一般入口保留原本預設。

已驗證：六個 bundle 的舊主題資料一致、9 組 A/B 配對完整、A/B/2×2/3×3 PDF 版面、六種遊戲圖片載入、390px 手機無橫向溢出。
